# googleplatstoreEDA
Exploratory Data Analysis and Data Cleaning of the Google Play Store Dataset using Pandas,Numpy and Matplotlib.

Project: Exploratory Data Analysis (EDA) on Google Play Store Dataset
# Description about the Dataset 
The columns in the dataset are : 
Apps,Category,Ratings,Reviews,Size,Installs,Type,Price,Content Rating,Genres,Last Update,Current Version,Android Version.
The dataset contains the metadata of the android applications available on the Google Play Store.
# Objective of this EDA
-To Clean the data and do feature engineering
-To do exploratory data analysis
-To visualize the data in matplotlib
# Tools used to complete this EDA
-Pandas
-Numpy
-Matplotlib
# Steps to do the EDA
-Analyze the meaning of data and how can we do feature engineering
-Clean the data according to the need 
-Do the EDA by answering the questions
-Visualize the result into graphs and charts using matplotlib
# Observation from the data
-It shows that how many app contains the word 'astrology' irrespective of how it is entered in the dataset.
-It calculates the average rating of the apps which is given to them on google playstore.
-It calculates the total number of unique categories that each app can have.
-It shows the average rating each category have from highest to lowest.  
-It shows that how many apps has received a rating of 5.0 on google playstore.
-It shows which type of apps are mostly available on the google playstore.
-It shows that which app has got the most number of reviews on the google playstore but we should not confuse it with number of positive reviews.
-It shows that which type of app has got better average rating and we can see that even if the apps are charging for the services but the average rating of the sevices is better than those of the free apps which indicates that they are delivering the experience that people has paid for.
# Limitations of this EDA
-No use of Seaborn
-No dirct conclusion can be drawn
-No statistical analysis
# Outcome
The analysis helps to understand patterns in app categories, ratings, installs, pricing, and user reviews to extract meaningful insights about the Android app ecosystem.
